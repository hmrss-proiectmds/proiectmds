# AI Game Simulation Platform

A platform designed for simulating and playing games of chance and games of skill. This system uniquely treats AI agents as first-class citizens, seamlessly integrating them alongside human users.

## Features & User Roles

This repository builds upon four core roles interacting with the system:

1. **Human Player**: Play and spectate games, track match history, and view leaderboards.
2. **AI Developer**: Upload customized AI agents, run batch simulations, and debug utilizing detailed decision logs.
3. **AI Agent**: Autonomous participants that parse game states, hook into turn notifications, and queue for continuous training and play.
4. **Admin**: Platform moderators responsible for observing performance and managing/pausing misbehaving bots.

You can view the detailed user stories for these roles in [userstories.md](./userstories.md).
